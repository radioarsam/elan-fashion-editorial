**ÉLAN** یک لندینگ‌پیج فارسی با حال‌وهوای مجلات لوکس فشن است؛ طراحی مینیمال، تایپوگرافی ظریف، تصاویر واقعی از ران‌وی و کمپین‌های خانه‌های مد و تجربه‌ای واکنش‌گرا برای موبایل و دسکتاپ.

> Fashion is not only what you wear. It is how you express yourself.

## ویژگی‌ها

- پیاده‌سازی با **HTML، CSS و JavaScript خالص**؛ بدون React، Bootstrap یا وابستگی اجرایی
- طراحی فارسی و راست‌چین با فونت Vazirmatn
- واکنش‌گرا برای موبایل، تبلت و دسکتاپ
- منوی موبایل با وضعیت دسترس‌پذیر و انیمیشن ورود سکشن‌ها
- رعایت `prefers-reduced-motion` و متن جایگزین تصاویر
- تصاویر نمونه از گزارش‌های ران‌وی Dior با لینک منبع و اعتبار رسانه

## اجرای محلی

نیازی به نصب پکیج یا build نیست. کافی است فایل `index.html` را در مرورگر باز کنید؛ یا با افزونه Live Server در VS Code اجرا کنید.

```bash
git clone https://github.com/radioarsam/elan-fashion-editorial.git
cd elan-fashion-editorial
```

سپس `index.html` را باز کنید.

## انتشار روی GitHub Pages

ورک‌فلو موجود در `.github/workflows/pages.yml` با هر push روی شاخه `main` سایت را منتشر می‌کند. در تنظیمات مخزن، بخش **Settings → Pages → Build and deployment** را روی **GitHub Actions** قرار دهید. پس از اجرای موفق workflow، دمو در نشانی بالا در دسترس خواهد بود.
